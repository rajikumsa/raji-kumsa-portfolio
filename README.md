## 💻 Local Development

```bash
# 1. Clone the repository
git clone https://github.com/rajikumsa/raji-kumsa-portfolio.git
cd raji-kumsa-portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build
```
